# Agent instructions

Before work in this repository, read [CLAUDE.md](CLAUDE.md).
It defines the shared procedures for all coding agents.

Without the user's explicit commit command, do not commit changes.
Without the user's explicit push command, do not push changes.
Permission to edit files does not give permission to commit or push them.
If repository procedures disagree with the user's instructions, obey the user's instructions.

Before an application change, read the applicable application README.
Keep unrelated local changes.
Give the user the verification results and remaining limitations.
